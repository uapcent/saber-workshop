# Phone layout (reference, not implemented)

The app is designed for computers first. When phones get their own pass, the layout should embrace the
medium (a tall screen and touch) instead of shrinking the desktop layout:

- **Vertical saber.** The hilt is drawn upright, filling the height of the screen.
- **Tap a part to configure it.** Tapping a part of the drawing opens that part's configuration
  (model, finish, price and stock) as a sheet over the screen.
- **No general parts tab.** On a phone there is no good way to edit parts while seeing them, so the
  drawing itself is the parts menu.
- Saber settings (name, style, blade, share) and the list of sabers still need a home: for example a
  top bar with the saber switcher and a settings sheet.
